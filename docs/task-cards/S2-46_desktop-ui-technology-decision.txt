What changes:

- Capture mandatory evaluation criteria.
- Require explicit owner approval before any runtime desktop UI implementation.
- Preserve server as the control plane.

Candidate technology families to evaluate without selection:
- .NET MAUI Desktop
- WPF
- WinUI 3
- Avalonia
- Uno Platform
- Electron / Tauri-style shell, explicitly non-default unless approved
- Other option, only if justified against the mandatory criteria

Mandatory evaluation criteria:
- Alignment with C# / .NET 10.
- Standalone launchable app/executable.
- File picker and large video file handling.
- SHA-256 hashing of local video bytes.
- Direct client -> site upload boundary.
- Offline/local queue potential.
- Secure token/session storage.
- Shared UI reuse potential with App.UI.Shared, without forcing browser/PWA.
- Testability.
- Packaging/update story.
- Maintenance risk for a small team.
- Windows-first practicality, unless owner approves broader desktop scope.

Explicit decision output required:
- Chosen technology or deferred decision.
- Rationale.
- Consequences.
- Risks.
- Rollback/revisit criteria.
- Next implementation branch/task, only after approval.
